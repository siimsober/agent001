# Breast Cancer PRS Device Development Plan

## Phase 1: Foundation (Weeks 1-4)
- Define clinical context & intended use
- Literature review on validated SNPs
- Establish analytical validity requirements
- Create regulatory strategy document

## Phase 2: Software Development (Weeks 5-12)
- Algorithm design & validation cohort analysis
- Software architecture (secure, auditable)
- Clinical validation study protocol
- Risk classification thresholds

## Phase 3: Regulatory Prep (Weeks 13-16)
- Compile technical file per IVDR Annex II
- Quality management system documentation
- Post-market surveillance plan
- Notified body readiness checklist

## Phase 4: Notified Body Submission (Week 17+)
- Quality review
- Clinical evidence assessment
- Software verification & validation

**Critical Path Items:**
- Secure validation cohort (genetic + clinical data)
- Define analytical/clinical validity metrics
- Establish cybersecurity & data privacy controls
- Document risk stratification evidence

**Next Daily Task:** Complete intended use statement & regulatory classification confirmation (Class IIb likely).

**Need:** Resources for clinical cohort, regulatory expertise, software QA/QMS infrastructure.
